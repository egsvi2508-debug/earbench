# Earbench

Quick tests of musical hearing. Each ends in one number and a rough estimate of how it compares:

- **Pitch Sense**: smallest pitch difference you can hear (adaptive staircase, cents)
- **Tone Sequence**: longest sequence of tones you can repeat
- **Steady Beat**: how evenly you keep a beat after the click stops (ms)
- **Melody Memory**: same or different, with melodies that grow
- **Sound Reaction**: reaction time to a beep (ms)
- **Perfect Pitch**: name notes with no reference

Comparisons are estimates from published research, not live player data. Scores are kept in the browser.

```bash
npm install
npm run dev
npm run deploy   # builds and pushes dist to gh-pages
```
